# Changelog

## 0.1.0

Initial release of Helvetium Apiary with durable jobs, queues, workers, cron/every/one-shot schedules, retries/backoff, priorities, delayed jobs, deduplication, dead-letter queues, progress/cancellation, workflow helpers, notification channels, lock/lease/semaphore/counter primitives, storage abstractions, memory and file-backed stores, observability hooks, graceful shutdown, and optional Helvetium Boot integration.
